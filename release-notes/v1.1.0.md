# WordIsle 1.1.0 · 体验升级与安全加固

> GitHub Release v1.1.0 的发布说明。完整版本历史见仓库根目录 [CHANGELOG.md](../CHANGELOG.md)。

## ✨ 新功能

- **联网检查更新**：启动时静默检查 GitHub Releases，发现新版本在顶栏提示，可一键跳转下载
- **更新日志常驻文档**：应用内「📖 更新日志」自动拉取最新内容，离线保留兜底文案
- **数据目录可配置**：在「偏好设置」中自选数据存储位置，支持迁移已有数据
- **应用菜单与快捷键**：标准菜单（文件 / 编辑 / 视图 / 窗口），支持 `Cmd+,` 偏好设置、`Cmd+N` 新建、`Cmd+O` 导入、`Cmd+E` 导出、`Cmd+D` 夜间、`Cmd+F` 专注
- **双击文件导入**：访达中双击 `.myisland` 文件可直接导入
- **DMG 安装引导**：从 DMG 运行时提示自动安装到 /Applications，自动清除隔离并推出 DMG

## 🎨 体验改进

- 字体本地化：思源宋体 + 霞鹜文楷打包到应用内，不再依赖网络 CDN
- 数据版本控制：引入 `__version` 字段，为未来数据结构升级预留迁移机制
- 设置持久化：换机不丢字体、字号等偏好设置
- DMG 背景图优化：修复背景图消失、图标过小不居中

## 🔒 安全与稳定性

- 原子写入：数据文件采用临时文件 + rename，防崩溃 / 断电损坏
- 内容安全策略（CSP）：限制资源来源，仅放行 GitHub API
- 安全加固：关闭 Node.js 集成、开启上下文隔离、外链仅放行 github.com
- 单实例锁 + 关闭时同步落盘

## 📦 下载

- macOS (Apple Silicon)：`WordIsle-1.1.0-arm64.dmg`
- Windows (x64)：`WordIsle-1.1.0-win32-x64.zip`

## ⚠️ 安装提示

- **macOS**：首次安装需执行 `xattr -cr` 清除隔离属性（详见 README 安装步骤）。本应用未签名，这是 macOS 对未签名应用的常规限制。
- **Windows**：未签名，首次启动可能被 SmartScreen 拦截，点「更多信息」→「仍要运行」即可。
